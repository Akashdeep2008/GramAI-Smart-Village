GramAI Water Sector
===================

This is a static student prototype. It has no AI scanner, chatbot, backend,
API key, or installation requirement.

To open:
1. Extract GramAI-Water-Guide.zip.
2. Open the GramAI-Water-Guide folder.
3. Double-click index.html in Chrome or Edge.

The rainwater calculator estimates roof runoff using area x rainfall x a
rough runoff factor. It is only a planning estimate, not an engineered design
or guaranteed supply. Actual collection varies with roof, rain, losses, storage,
filters, and local conditions.

For water quality concerns, use official local public-health/water-supply
instructions and authorized testing resources. This prototype does not test
water or provide chemical treatment instructions.

Official resources linked in the site include the Central Ground Water Board
(CGWB) and Jal Jeevan Mission (JJM).
