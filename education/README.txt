GramAI Education Sector
=======================

This is a static student prototype covering learning pathways for children,
school students, youth, college learners, working adults and older learners.
It has no AI, backend, API key, or installation requirement.

To open:
1. Extract GramAI-Education-Guide.zip.
2. Open the GramAI-Education-Guide folder.
3. Double-click index.html in Chrome or Edge.

The learner-stage selector suggests links to official education resources.
This site does not provide admission, scholarship or course eligibility
decisions. Confirm deadlines and current requirements with the official provider.

Official sources linked in the project include DIKSHA, ePathshala/NCERT,
SWAYAM, SWAYAM Plus, the National Scholarship Portal, ULLAS, NIOS and
Rashtriya e-Pustakalaya.
