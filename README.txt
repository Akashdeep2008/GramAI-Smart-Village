GramAI Complete Student Prototype
=================================

This ZIP combines the GramAI home page and five sector webpages into one
static website folder. The pages are linked through a shared sector navigation.

To open:
1. Extract GramAI-Complete-Site.zip.
2. Open the GramAI-Complete-Site folder.
3. Double-click index.html to open the home page in Chrome or Edge.
4. Select any sector card or use the sector bar to move between pages.

Contents:
- Agriculture: 60 crop-care reference guides
- Water: conservation, rainwater harvesting, irrigation and water-quality resources
- Health: public-health pathways and official service links
- Education: age-spanning learning pathways and official resources
- Infrastructure: village assets, official portals and a local issue-note builder

This is a student prototype, not an official government website. The site does
not connect to live village data, submit complaints, or require an AI API key.
Official service links are provided for reference. Confirm current service details
with the relevant government portal or local authority.
